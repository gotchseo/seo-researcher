# Distribution launch queue

The repository is prepared for the MCP Registry and Agent Plugins-compatible marketplaces. Submit only after the production MCP OAuth flow and first research packet pass end-to-end verification.

1. MCP Registry: authenticate `mcp-publisher` with the `gotchseo` GitHub identity and publish `server.json`.
2. Codex/OpenAI plugin directory: submit the repository's Codex manifest and hosted OAuth MCP endpoint.
3. Anthropic Connectors Directory and Claude plugin marketplace: submit the same remote MCP and public repository.
4. Cursor Marketplace: submit the root Agent Plugin repository at `cursor.com/marketplace/publish`; also list it on cursor.directory.
5. Gemini CLI Extension Gallery, OpenClaw ClawHub, GitHub Copilot/VS Code MCP gallery, and Windsurf Marketplace.
6. Smithery, Glama, PulseMCP, mcp.directory, and mcp.so.
7. Postman API Network using `openapi.yaml`; then evaluate RapidAPI.
8. Build native templates for Zapier, Pipedream, n8n, Make, Composio, Arcade, and Toolhouse after real API usage reveals the highest-value automations.

Use source-specific campaign parameters on every submission link. Analytics must distinguish listing impression/click, signup, OAuth connection, first successful packet, trial conversion, and retained weekly use by directory and client.
